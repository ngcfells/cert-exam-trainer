# CY0-001 sources

Where each value in `src/banks/secai/meta.ts` came from. Checked 2026-10-31.

| Value | Source |
| --- | --- |
| Code CY0-001, version V1, launch 17 February 2026, retirement about 3 years after launch (no date given) | <https://www.comptia.org/en-us/certifications/secai/> |
| Maximum 60 questions, 60 minutes, passing score 600 (100–900), multiple-choice and performance-based | Same page, and Exam Objectives v4.0, "Test details" |
| Domains and weightings (17 / 40 / 24 / 19) | Same page, and Exam Objectives v4.0, "Exam objectives (domains)" table |
| Objective numbers and titles 1.1–4.3 (15 in all) | CompTIA SecAI+ CY0-001 V1 Exam Objectives, Document Version 4.0 (PDF, © 2025 CompTIA) |
| Official acronym list (63 terms) | Same PDF, "CompTIA SecAI+ Acronym List" |

Notes:

- The objectives PDF is not stored in this repository; CompTIA prohibits redistributing it. Download it from the CompTIA SecAI+ page.
- **Use v4.0.** Version 1.1 of the objectives also circulates. It has the same 15 objective titles, but v4.0 adds federated learning, backdoor and trojan attacks, the MCP server, differential privacy, awareness training and shadow IT/AI, and only v4.0 fills in the test details.
- Acronyms are stored as printed, including mixed case (`DDoS`, `DoS`, `IaC`, `IdP`, `MLOps`, `OAuth`) and compound terms (`CI/CD`, `PCI DSS`, `SOC 2`). The coverage check counts `CI`, `CD`, `PCI`, `DSS` and `SOC` as covered because they are parts of listed terms (`acronymCovered`).
- On this exam `IP` means Intellectual Property and `SOC` means Security Operations Center (`SOC 2` is System and Organization Controls 2).
- The PDF prints ATLAS as "Adversarial Threat Landscape for Artificial Intelligence Systems" in the acronym list and with a hyphen ("Artificial-Intelligence") in objective 2.1. We store the acronym-list spelling.
